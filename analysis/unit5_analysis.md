# Анализ кода `Unit5`

## Ключевые проблемы

1. **Утечки ресурсов и отсутствие `try..finally`**:
   - `HTTPClient := THTTPClient.Create;` создаётся в `Zapros`, но не освобождается.
   - `JSONData`, `JSONValue` и другие JSON-объекты создаются через `ParseJSONValue`, но не освобождаются.

2. **Повторное подключение к БД и смешение ответственности**:
   - В `Zapros` и `FormCreate` многократно повторяются строки настройки `FDConnection1`.
   - Сетевой запрос, парсинг JSON и запись в SQLite находятся в одной процедуре `Zapros`.

3. **Опасное освобождение компонента формы**:
   - В `FormCreate` после `SELECT * FROM Names` вызывается `Form5.FDQuery1.Free;`.
   - `FDQuery1` — дизайнерский компонент формы, его нельзя освобождать вручную в рантайме, иначе возможны AV при следующих обращениях.

4. **Избыточный/ошибочный парсинг JSON**:
   - JSON парсится несколько раз подряд (`ParseJSONValue(Response.ContentAsString)` и затем через `JSONString` снова).
   - Нет проверок на `nil` после парсинга и приведения типов.
   - Используется кириллический ключ `'Виды работ'` без fallback-проверок.

5. **Потенциальные проблемы потокобезопасности и UX**:
   - В `onReceive` обновляется UI (`Form5.Label2.Text`) без явной синхронизации для всей логики; `TThread.Queue` присутствует, но фактически почти не используется.
   - Синхронный HTTP-запрос в UI-потоке может «подвешивать» интерфейс.

6. **Безопасность**:
   - Жёстко зашитые учётные данные: `Буйвидович_А:111111`.
   - Нешифрованный протокол `http://...` для передачи Basic Auth.

7. **Слабая обработка ошибок**:
   - Почти нет проверок `Response.StatusCode` кроме `200`.
   - В блоке `except` выполняется создание таблицы без анализа причины ошибки.

## Что исправить в первую очередь

1. Вынести работу с БД в отдельный сервис/методы: `InitDb`, `InsertPersonWork`, `LoadCachedPerson`.
2. Добавить `try..finally` для `THTTPClient` и всех JSON-объектов.
3. Удалить `FDQuery1.Free` из `FormCreate`.
4. Сделать единичный парсинг JSON + проверки `Assigned`/`nil`.
5. Убрать хардкод логина/пароля и перейти на HTTPS.
6. Выполнять `Zapros` асинхронно (например, `TTask.Run` + безопасное обновление UI через `TThread.Queue`).

## Минимальный безопасный рефакторинг

- `Zapros`:
  - `HTTPClient := THTTPClient.Create;`
  - `try`
    - выполнить запрос
    - распарсить JSON **один раз**
    - заполнить `ListBox1` и БД
  - `finally`
    - `HTTPClient.Free;`
    - `JSONValue.Free;`
  - `end;`

- `FormCreate`:
  - оставить только инициализацию/регистрацию ресивера;
  - не освобождать компоненты, созданные дизайнером (`FDQuery1`).
